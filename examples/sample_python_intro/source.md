# Getting Started with Python

Python is a powerful and versatile programming language that is widely used for web development, data analysis, artificial intelligence, and more. It was created by Guido van Rossum and first released in 1991.

## Installation

Before you can start coding in Python, you need to install it on your computer. Visit the official website at `https://www.python.org` and download the latest version for your operating system.

The installation process is straightforward on most platforms. On Windows, simply run the installer and make sure to check the box that says "Add Python to PATH".

## Your First Program

Once Python is installed, you can write your first program. Create a file called `hello.py` and add the following code:

```python
print("Hello, World!")
```

Run the program by typing `python hello.py` in your terminal. You should see the greeting appear on your screen.

## Variables and Data Types

Python supports several basic data types including `int` for integers, `float` for decimal numbers, `str` for text, and `bool` for true/false values. Variables are created automatically when you assign a value to them.

## Key Features

Here are some reasons why developers love Python:

- Readable and clean syntax
- Large standard library
- Strong community support
- Cross-platform compatibility

Python is an excellent choice for both beginners and experienced developers alike.
