# Glossary Build Prompt Template

## Контекст

Документ: `{document_title}`
Язык оригинала: `{source_lang}`
Целевой язык: `ru` (русский)

## Цель

Создать глоссарий терминов и style guide для перевода этого документа.

## Инструкции

1. **Глоссарий**: найди специфические термины, имена собственные, терминологию предметной области. Для каждого термина предложи русский перевод. Если термин устоявшийся в русском языке — используй его.

2. **Style Guide**: определи тон, стилистику, особенности перевода. Учти:
   - Аудитория: `{audience}`
   - Тип документа: `{document_type}`
   - Формальность: `{formality}`

3. **Непереводимые элементы**: отметь что НЕ нужно переводить (бренды, модели, названия продуктов и т.д.)

4. **Примеры перевода**: если в тексте есть сложные фразы — покажи как их лучше перевести.
