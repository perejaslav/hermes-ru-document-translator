## Что проверять

1. **Полнота** — весь текст переведён, ничего не пропущено
2. **Глоссарий** — термины переведены согласно глоссарию
3. **Стиль** — соответствует style guide
4. **Структура** — сохранены заголовки, форматирование, BLOCK_ID/CHUNK_ID
5. **Защищённые фрагменты** — code blocks, URLs, email не переведены
6. **Естественность** — перевод читается как текст на русском, не как машинный перевод
