1. Переводи ТОЛЬКО текст на языке `{source_lang}`. Не переводи code blocks, URLs, email-адреса, технические идентификаторы.
2. Сохраняй структуру заголовков и форматирование Markdown.
3. Используй термины из глоссария.
4. Соблюдай style guide.
5. Если встречаешь {protected_placeholder}, НЕ переводи содержимое — оставь как есть.
6. Перевод должен быть естественным для русского языка, не машинным.
7. Обязательно сохраняй все BLOCK_ID и CHUNK_ID метаданные без изменений.
